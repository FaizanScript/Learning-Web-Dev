# One Piece Crew Portal

A multi-page One Piece themed web application built using HTML, CSS, and JavaScript.

## Features

- Join the Crew registration form
- Profile picture upload
- Login and Logout system
- Form validation
- Crew member carousel
- Grand Line members section
- Local Storage data persistence
- Session-based authentication
- Dynamic background image transitions
- Responsive design
- GitHub Pages deployment

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Local Storage API
- Session Storage API
