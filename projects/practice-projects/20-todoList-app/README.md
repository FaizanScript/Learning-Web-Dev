# Todo Master

A modern Neumorphic To-Do List application built using HTML, CSS, and JavaScript.

## Features

* Add, edit, and delete tasks
* Task priorities (Easy, Medium, Hard)
* Due dates
* Search tasks
* Filter tasks
* Sort tasks
* Progress tracking
* Statistics dashboard
* Local Storage persistence
* Light and Dark Mode
* Responsive design
* Custom delete confirmation modal

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
